| D5 | 2026-09-28 | Primary dataset = Hannousse & Yahiouche (2021). Hannousse benign URLs are varied (61% with a path). Residual length bias remains (length-only AUC 0.664 vs 0.721) and is tested on Day 2. | `outputs/tables/url_shape_audit.csv`, `outputs/figures/url_length_by_class.png` |
| D6 | 2026-09-28 | Decoder = OpenCV QRCodeDetector, then QRCodeDetectorAruco only if the first returns nothing; no other preprocessing; same function for dataset, robustness and demo. QR settings fixed: EC M, box 10, border 4. | Fixed chain keeps decode rates comparable; a mismatch is not a usable decode. | `src/qr_decoder.py`, `qr_generation_summary.json` |
| D7 | 2026-09-28 | Duplicates and label conflicts checked on a canonical URL (lowercase scheme/host, no default port, empty path -> '/'); original string kept for QR encoding. Registered domain (tldextract, bundled offline suffix list, ICANN suffixes only) and a host-free URL template stored for Day 2 grouped splitting and near-duplicate audit. Adopted after external methodology review, before any split or model. | Exact matching misses trivial variants; same-domain and same-template URLs across splits would leak. | `src/data_loading.py`, `data_cleaning_report.json` |
| D8 | 2026-09-28 | 30 offline URL lexical features fixed in URL_FEATURES (src/url_features.py) before any modelling; computed from the decoded payload; subdomains counted with the bundled public suffix list. | D9 | 2026-09-28 | log1p then StandardScaler for 17 count/length URL features (URL_LOG1P_FEATURES); StandardScaler only for flags, digit ratio, entropy. Fixed before training. | Reduces the influence of skewed counts on Logistic Regression; filter uses train data only. | `src/url_features.py`, `src/config.py` |
| D10 | 2026-09-28 | Generator QR version is descriptive only, never a model input. Predictive QR/image features must be computable from pixels for clean, distorted and uploaded images. | Prevents train/demo feature-availability leakage. | `docs/data_dictionary.md` |

| D12 | 2026-09-28 | Split groups = registered domain merged with non-trivial URL templates occurring >= 3 times (templates > 30 URLs treated as generic, reported, not merged). All fixed before any split exists. | Objective, reproducible rules instead of manual choices. | `src/config.py` |
| D13 | 2026-09-28 | QR/image model features (10) computed from pixels only on a standardised 512x512 copy; raw width/height descriptive only. Module count taken from the decoder's rectified grid (exact on clean, rotated, blurred and JPEG-30 test images, v3-v30); a geometric finder-pattern estimator was tested and rejected (unreliable above v6). log1p for blur score, component density and module count. | Features must be available and comparable for any upload resolution (D10); measured, not assumed, estimator reliability. | `src/qr_features.py`, `qr_feature_length_correlation.csv` |
